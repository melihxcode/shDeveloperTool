# Pasif katalog kayıtları

Bu klasördeki JSON dosyaları uygulama tarafından yüklenmez. EP5.4 referanslarını yeniden göstermek için `ep5.4-references.json` içindeki istediğiniz nesneleri `content/files-catalog.json` dosyasının `files` dizisine kopyalayın. `id` değerleri benzersiz kalmalı; JSON yorum satırı desteklemez. Ardından uygulamada Files → Refresh seçin.

`superseded-tools-2026-11-12.json` değiştirilen eski program kayıtlarını saklar. Güncel VS Code artık 32-bit Windows desteklemediğinden eski 32-bit sürümü aktif listede değildir. Restore etmeden önce bağlantıyı yeniden kontrol edin.
