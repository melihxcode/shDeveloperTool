# shDeveloperTool

Public Windows releases for **shDeveloperTools**, a desktop toolkit for Shaiya developers.

## Download
Open [Releases](https://github.com/melihxcode/shDeveloperTool/releases) and download **shDeveloperTools-win-Setup.exe** from the latest published release.

Install once with Setup.exe. The installed application checks this repository for newer stable releases. Draft and prerelease builds are not installed automatically. Portable builds do not enable the installed update flow.

## Release files
- Setup.exe: first Windows x64 installation.
- Full .nupkg and releases.win.json: automatic update package and manifest generated by Velopack.
- Portable.zip: portable distribution.

Application source code is maintained separately in the private source repository. This repository is only for distribution.
